# Pokémon Text Game

This was my first big Python project (built ~6 months ago).  
It’s a text-based Pokémon battle game with:

- Object-Oriented Programming (classes for Pokémon, Attacks, Abilities)
- Battle mechanics (speed, weaknesses, random encounters)
- Capture system with animations
- Simple pokedex to store caught Pokémon

# How to Play
 Download the repo
 Open the folder
 Run the game with: python pokemon_game.py
